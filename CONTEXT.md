# GMP Environmental Measurement Reporting

This context covers the environmental measurement records that are converted into reports and grouped by air handling unit and measurement period.

## Language

**AHU**:
An air handling unit whose environmental measurements belong together in one report group.
_Avoid_: Sheet, report

**AHU Identity**:
The positive AHU number recorded in a document's `해당 공조기` field, or in the source filename when that field is unreadable. A document without either value has no AHU Identity.
_Avoid_: Default AHU, assumed AHU

**AHU Measurement Record**:
The measurements in one test document for one AHU and one semester.
_Avoid_: AHU data set, PDF data
